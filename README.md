# Stellar Calc — Modern UI Redesign

เว็บเครื่องคิดเลขตัวละคร พร้อมระบบธีมจากภาพตัวละคร ประวัติการคำนวณ และโหมดท้าสู้ 1v1

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` ผ่านเว็บเบราว์เซอร์
3. หากต้องการเล่นโหมดออนไลน์ ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด PeerJS

## สิ่งที่ปรับปรุง
- ปรับโครงสร้างหน้าเป็น Modern Dashboard พร้อมส่วนหัวแบรนด์
- จัดเครื่องคิดเลขและแผงตั้งค่าเป็น 2 คอลัมน์บนจอใหญ่ และเรียงเป็นแนวตั้งบนมือถือ
- ลดเอฟเฟกต์แสงและแอนิเมชันที่รบกวนสายตา
- ปรับปุ่ม หน้าจอแสดงผล การ์ด ฟอร์ม และประวัติให้มีระยะห่างและลำดับสายตาชัดเจน
- ปรับหน้าต่างล็อบบี้และ HUD ของโหมดต่อสู้ให้เป็นรูปแบบเดียวกัน
- คงระบบคำนวณ การเปลี่ยนธีม/ดึงสีจากรูป การบันทึก localStorage และระบบต่อสู้เดิม

## ไฟล์หลัก
- `index.html` — โครงสร้างหน้าและองค์ประกอบ
- `style.css` — ธีมและ UI หลัก รวม Modern Redesign layer
- `battle.css` — รูปแบบ HUD และหน้าต่างโหมดต่อสู้
- `script.js` — logic เครื่องคิดเลขและธีม (คงเดิม)
- `battle.js` — logic โหมดต่อสู้ (คงเดิม)

หมายเหตุ: ระบบห้องออนไลน์ใช้ PeerJS ผ่าน CDN และการเชื่อมต่อแบบ WebRTC ตามโค้ดเดิม
